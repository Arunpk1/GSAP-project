# Summer Drink 🍋🥤

A simple animated landing page I created while learning frontend development and exploring GSAP for the first time.

This project was built using plain HTML, CSS, and GSAP through a script tag setup — before I learned React, Tailwind, backend development, and modern frontend workflows.

Even though it's an old project, it still feels special to me because it was one of the first times I experimented with animation and creative UI design.
